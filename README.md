# 🏆 Dynamic LeaderBoard System + Open Trivia Quiz

A full-stack web application that includes:
- 👤 User Profile System
- 🏅 Dynamic Leaderboard
- 🎮 Open Trivia Quiz Game
- 📊 Score tracking and backend submission

---

## 🚀 Features

### 👤 Profile System
- View user details dynamically
- Edit profile functionality
- Displays:
  - Username
  - Bio
  - Location
  - DOB
  - Gaming IDs (Steam, Epic)

---

### 🎮 Open Trivia Quiz
- Fetches questions from backend API
- Multiple-choice quiz system
- Auto score calculation
- Stores results in backend leaderboard system

---

### 🏅 Leaderboard System
- Tracks user scores per game
- Game-based scoring system
- Backend database integration
